# پلتفرم کارت ویزیت هوشمند NFC - برند CIPCard (cipcard.ir)

پلتفرم مدرن و لوکس فروش و مدیریت کارت ویزیت‌های دیجیتال و هوشمند NFC مبتنی بر PHP 8.2+ با ساختار ماژولار Clean MVC، روتینگ تمیز، درگاه پرداخت زرین‌پال نسخه ۴، پیامک یکبارمصرف (OTP)، ۵ قالب اختصاصی و تولید خودکار QR Code و vCard.

---

## 💎 ویژگی‌های کلیدی سیستم
1. **معماری استاندارد Clean MVC:**
   - توسعه یافته با PHP 8.2+
   - پایگاه داده امن با PDO و Prepared Statements جهت مصونیت ۱۰۰٪ در برابر SQL Injection
   - احراز هویت بدون رمز عبور (Passwordless OTP) و سیستم مدیریت امن نشست‌ها (Sessions & CSRF)
2. **لندینگ پیج لوکس با تم VIP:**
   - طراحی مشکی مات و طلایی (Matte Black & Gold)
   - انیمیشن‌های پارالاکس و سه‌بعدی تعاملی با **GSAP** و **ScrollTrigger**
   - پیش‌نمایش تعاملی ۵ قالب، مقایسه پلن‌ها و فرم ثبت سفارش آنی
3. **صفحه عمومی کارت هوشمند (`cipcard.ir/@[MobileNumber]`):**
   - بدون پسوند فایل با روتینگ خودکار `.htaccess`
   - ۵ قالب اختصاصی واکنش‌گرا (Mobile-First):
     - **قالب مینیمال و لوکس (Minimal Luxury)**
     - **قالب مدرن و گلسمورفیسم (Glassmorphism)**
     - **قالب شرکتی و رسمی (Corporate Pro)**
     - **قالب خلاقانه و نئون/تیره (Creative Dark)**
     - **قالب کارت ویزیت کلاسیک با چرخش سه‌بعدی (Modern Card 3D Flip)**
   - ۳ پالت رنگی برای هر قالب (طلایی-مشکی، آبی-سرمه‌ای، سبز زمردی-طوسی)
   - تولید خودکار **بارکد اختصاصی QR Code** برای هر شخص
   - دکمه دانلود و ذخیره مستقیم مخاطب در گوشی با فایل استاندارد **`vCard (.vcf)`**
4. **پنل کاربری مشتریان (User Dashboard):**
   - پیگیری مرحله به مرحله وضعیت سفارش با استپر گرافیکی (ثبت سفارش -> بررسی/طراحی -> چاپ چیپ NFC -> ارسال پستی)
   - امکان آپلود فایل طرح یا لوگوی اختصاصی برای کارت‌های Custom Design
   - ویرایش آنی مشخصات، بیوگرافی، شماره‌ها و لینک‌های شبکه‌های اجتماعی
   - امکان سوئیچ لحظه‌ای بین ۵ قالب و پالت‌های رنگی
5. **پنل مدیریت پیشرفته (Admin Panel):**
   - آمار مالی، سفارشات و نمودار فروش ۳۰ روز اخیر با **Chart.js**
   - فیلتر و مدیریت وضعیت سفارش‌ها و ثبت کد رهگیری پستی
   - مدیریت کاربران با امکان ویرایش کامل مشخصات و شماره موبایل
   - لاگ تراکنش‌های زرین‌پال با RefID، مبلغ، تاریخ و شماره کارت
   - مدیریت داینامیک قیمت‌ها، تنظیمات درگاه و وب‌سرویس پیامک

## 🚀 راهنمای نصب و راه‌اندازی

### ۱. نیازمندی‌ها
- وب‌سرور Apache (با فعال بودن `mod_rewrite` و `mod_headers`)
- PHP نسخه 8.2 یا بالاتر (اکستنشن‌های `pdo_mysql`, `curl`, `json`, `mbstring`)
- پایگاه داده MySQL 5.7+ یا MariaDB 10.3+

### ۲. ایمپورت دیتابیس
اسکریپت موجود در مسیر `database/database.sql` را در دیتابیس خود ایمپورت نمایید.

### ۳. تنظیم مشخصات دیتابیس
فایل `app/Config/database.php` را باز کرده و اطلاعات دیتابیس خود را وارد کنید:
```php
public const DB_HOST = '127.0.0.1';
public const DB_NAME = 'cipcard_db';
public const DB_USER = 'root';
public const DB_PASS = '';
```

- **رمز عبور:** `Admin@CIPCard2026`
- **آدرس ورود مدیریت:** `cipcard.ir/admin/login`
